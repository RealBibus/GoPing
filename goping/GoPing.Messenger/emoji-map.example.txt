# Unicode-маппинг для локального набора emojiP.
# Скопируйте этот файл как emojiP/emoji-map.txt и заполните соответствия.
# Формат: номер картинки=Unicode-символ (можно несколько символов, например флаги).
# Записи без '=' и строки, начинающиеся с '#', игнорируются.
# Если соответствия нет, в сообщение уходит токен вида :emoji_42: .
#
# Как это работает:
#   - при клике по картинке отправляется Unicode-символ, а не токен;
#   - у вас дома этот символ снова рисуется картинкой из пака;
#   - у других пользователей показывается обычный Unicode-эмодзи.
#
# Пример (номера нужно подобрать под свой набор):
# 1=😀
# 42=❤️
# 100=🇷🇺
